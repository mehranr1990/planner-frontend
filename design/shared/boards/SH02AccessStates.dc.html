Banners sit directly under the page header, full width, never dismissible while the condition holds. One banner at a time (priority: revoked › offline › archived › conflict › read-only › guest).
No discoveryForbidden and not-found render the SAME screen and copy. No project name, member count or file name is ever shown to someone without access.
Full page vs bannerFull page: loading, empty, error, unauthenticated, not available, invite pending, revoked, deleted. Banner over normal content: offline, archived, read-only role, verified guest, conflict notice.
RevocationOn revoke/logout/context switch: clear scoped query cache, file thumbnails, drafts and open sheets; close realtime listeners; then show “access removed”.
Pending invitationShows only public-safe preview (project name, inviter, offered role). No tasks, members or files until accepted with a verified account.
ConflictNever overwrite silently: compare (mine vs theirs, field by field) → keep mine / keep theirs / merge text fields.
Actions disabled vs hiddenHidden when the user cannot see the resource; disabled with a one-line reason when they can see it but their role cannot act.
MockingEvery state is reachable in the UI mock through a demo-state switch (same pattern as /styleguide/my-day?state=…).
CopyEN/FA strings on the cards are final copy keys (namespace Access.*).
