SPECIFICATION · switch tabs to read each part
48 hoursMeasured from the server-committed time; the server decides on every command. UI shows “n h left” in the menu; at 0 the item changes, never a client-side guess.
EditAuthor only, ≤ 48h, active member. Label “edited”; revisions not shown to others.
Delete for everyoneDirect and private groups: author ≤ 48h. Work channels: author ≤ 48h only if the channel policy allows. Shows a tombstone to everyone, also in search, replies and notifications.
Delete for meAny time; hides only for you (also in search, pagination, reconnect). Others unchanged.
ModerationWorkspace admins/moderators may remove messages in work channels (audited, labelled “removed by moderator”). Not available in direct messages.
Forward / pinOnly to conversations where you may post; pin per policy.
KeyboardHover toolbar is also reachable with ↑ / Tab; context menu via Shift+F10; long-press on touch.
