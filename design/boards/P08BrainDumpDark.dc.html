Chosen: continuous daily page with line-level sorting. Feels like paper, not a task editor.
Zero frictionOpening Brain Dump puts the cursor in today’s page. No title, type, date, context or destination fields — ever.
Auto-saveSaves on every pause (600ms). Status chip “Saving… / Saved · time / Offline · will sync”.
SortingHover a line or select text → action row: Task · Note · Journal · Event · Inbox · Strike. Sorted lines stay visible, muted, with a “→ destination” tag (click opens it).
Brain Dump vs InboxInbox = discrete captures awaiting a decision. Brain Dump = free thinking. “Send rest to Inbox” turns each unsorted line into an Inbox item.
PagesOne page per day (new page at 04:00). Left list shows unsorted counts. Old pages never nag.
Typography19px / 1.5 body, generous margins, no rich-text toolbar (Markdown shortcuts only: - list, [] checkbox).
SignatureThe page is a signature sheet with an empty sculpted corner — the only decoration on the screen.
PrivacyCovered by the Journal lock setting if enabled (same sensitivity).
