Mehran Planner · Phase 1

Design rationale

The six answers the brief asks for before high-fidelity screens. Everything here is already live in the desktop shell next to this board.

01

Shape language

  • Capsule for every control: buttons, chips, inputs, switchers, nav items.
  • Sculpted card, 24–32px radius, for product surfaces.
  • Notch (cut-out with soft fillets) is the signature move. A corner notch holds a card’s primary action; a top-centre notch holds people.
  • The notch is rationed to signature surfaces: hero, health, focus, nav, insight. Never on utility.
02

Navigation system

  • Command bar: floating pieces, not a toolbar: logo · context switcher · schedule · search ⌘K · create · notifications · profile.
  • Context switcher opens to Personal / Projects / Teams / Companies; each expands to pick the workspace.
  • Floating rail: icon-only by default, expands to labels with a button (never hover-only). Items change per context.
03

Hierarchy

SIGNATURENotch, accent, motion. One or two per screen.
PRODUCTPlain sculpted card, scope tint as cue.
UTILITYFlat, compact, dense. Forms, tables, filters.

Large type only inside signature zones. Body stays 14–15px for long sessions.

04

Card logic

  • Surface tells state. White = content · Volt = happening now · Ink = focus/panel · Scope soft = context cue.
  • One primary action per card, placed in the notch when the card is signature, at the bottom otherwise.
  • Anatomy: tag row → title → meta → footer (people · progress · counts). Same order everywhere.
  • Max one volt card per viewport (the 5% rule).
05

Mobile adaptation

  • Context switcher moves to the top as a capsule; the rail becomes the floating bottom bar.
  • Quick-add sits in the bar’s notch and opens a sheet: Task · Expense · Mood · Note · Habit · Event.
  • Popovers become bottom sheets. Task detail is full-screen with sticky Complete / More.
  • 44px minimum targets; desktop-only grids collapse to stacked surfaces, timeline goes full width.
06

Motion strategy

120mspress, toggle
220mspopover, sheet
360mscontext, layout
  • Springs with high damping (no bounce). Context switch morphs the scope tint and slides the rail.
  • Counters and rings animate once on load; the “now” marker drifts in real time.
  • Honour reduced-motion: swap movement for fades.
