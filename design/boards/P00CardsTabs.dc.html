Signature cardStandalone, important product object. Sculpted top-right corner (64px cut, 28px fillets). May hold ONE primary action (54px circle) — or stay empty as negative space. May carry live state (volt).
Product cardStandard surface. 24–28px radius, optional scope tint, moderate content, no notch.
Utility cardFilters, form groups, settings groups, KPI tiles, empty-state containers. 16–20px radius, #F8F8F6 or white, no decoration.
Standalone vs groupedOne important object → signature allowed. Repeated / dense → product or utility. Related family (KPIs, metric groups, people, rows) → one shared clean geometry, never a notch per item.
Empty notchAllowed and encouraged on 1 card per view when it creates hierarchy (Insight, Weekly Story, Goal summary). Do not stuff an icon into every cut-out.
Action in notchExactly one action, always circular, always the card’s primary (Start focus, Open, Expand, Add). Never a menu of icons. Secondary actions live inside the card.
Never notchTask rows, list items, table rows, board cards, inputs and form sections, filter panels, settings groups, KPI tiles, chart tiles in a grid, toasts, sheets.
DensityMax 3 signature cards per desktop viewport (Overview and My Day use 3), 1–2 per mobile viewport. Only one may be volt.
RTLThe sculpted corner mirrors to top-left; action stays in it.
DarkNotch background = page graphite #121412; card surface steps #1C1F1C; the corner reads by surface contrast, no outline.

Selection ruleView mode → Segmented. Small local option → Compact pills. Mode needing emphasis → Filled pills. Sections of one object → Folder tabs. Global destination → Navigation (rail / bottom nav), never tabs.
Folder geometryActive tab is 56px tall, 24px top radius, shares the panel background and connects with 20px concave fillets on both sides (left fillet hidden on the first tab, where the panel corner becomes square). Inactive tabs are 44px outlined capsules. No gap between active tab and panel.
Bottom tabsSame geometry flipped (RingCard). Equal-width uppercase labels. Use for 2–3 views of one compact object (History / Details).
Do not use folder tabs forGlobal navigation, Day/Week/Month, List/Board, binary toggles, dense filter sets, wizard steps.
CountsOptional count after the label (12px, muted). Never coloured badges inside folder tabs.
RTL / DarkFillets mirror with direction. In dark the panel and active tab use the card surface #1C1F1C on graphite #121412.
ComponentOne reusable FolderTabsCard {tabs[], value, onChange, variant: top | bottom-even, surface}. Keyboard: ←/→ moves, Home/End, role=tablist/tab/tabpanel.
